# موافقات المالية

تم توحيد واجهة المالية مع الألوان البنفسجية والخطوط والقائمة الجانبية المستخدمة في التصميم.
شاشة الموافقات تستغل مساحة المحتوى المتاحة، مع عنوان واضح وفلاتر للحالة ونوع الطلب، ومنها الرواتب.

الجدول يحتوي على شريطي تمرير أفقي ورأسي ظاهرين وقابلين للسحب. أسماء الأعمدة ثابتة أثناء التمرير
الرأسي، والعناوين والصفوف تستخدم نفس عروض الأعمدة. أسماء الموظفين الطويلة تلتف ويمكن تحديدها
ونسخها. عمود الإجراءات هو الأخير. على النوافذ القصيرة أو الضيقة يمكن تمرير الشاشة للوصول إلى
الفلاتر والترقيم، مع بقاء تمرير الجدول مستقلًا.

تم تعريب نوع تصحيح الحضور ودور مدير المالية، وإضافة ألوان هادئة للحالات وأزرار واضحة لعرض التفاصيل
والموافقة والرفض. صلاحية اتخاذ القرار تظل مرتبطة بالدور المطلوب في الطلب؛ لم تتغير بيانات الموافقات
أو مسارات حفظها أو قواعد اعتماد الرواتب.

الاختبارات تشمل العربية والإنجليزية عند عروض 320 و768 و1440، وتكبير الخط 130%، والوصول إلى إجراءات
أول وآخر صف، ونافذة 320×380 وفلاتر الرواتب، ومنع ظهور أزرار القرار للدور غير المسؤول.
