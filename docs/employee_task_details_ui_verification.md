# تفاصيل المهمة للموظف العادي

تطبيق مرجع «03 تفاصيل المهمة» في مساحة عمل الموظف، بالهوية البنفسجية والعربية RTL مع دعم الإنجليزية. فُحصت حالة Git وحُفظت التعديلات السابقة. لا تعديل لقاعدة البيانات أو نشر إلى GitHub أو تغيير لتصميم HR والمدير.

## الواجهة والسلوك

- تُفتح تفاصيل المهمة داخل مساحة العمل بدل النافذة القديمة. زر العودة ثابت أعلى الصفحة، وتُحفظ فلاتر البحث والحالة ونوع المهمة عند الرجوع.
- عنوان ونوع المهمة الحقيقيان، وملخص للأولوية والموعد والحالة ونسبة التقدّم.
- أقسام مستقلة للوصف، والوقت المقدّر والمسجّل، والمرفقات، وسجل المتابعة. عمودان على العرض المناسب وعمود واحد على الموبايل أو مع تكبير النص.
- طلب المراجعة وبدء/إيقاف المؤقت يستخدمان وظائف المستودع الحالية. التسجيل اليدوي من قائمة الإجراءات الإضافية.
- قسم تحديث المهمة يحفظ تعديل الحالة والتقدّم الموجودين. تعطيل الإجراءات أثناء العملية، وتحديث التفاصيل بعد نجاح الحفظ، ورسالة خطأ عند الفشل.
- المرفقات تعرض الاسم وتاريخ الإضافة المتاحين، وتفتح الرابط الحقيقي. الإضافة باستخدام اختيار الملف الحالي.
- سجل المتابعة يُبنى من التواريخ المحفوظة ويُرتّب زمنيًا: الإنشاء والاستلام والبدء والإكمال وطلب المراجعة ومراجعة المدير. تظهر ملاحظات المراجعة وحالة الجودة الموجودة. السجل ليس سجل تدقيق شاملًا؛ الأحداث غير المحفوظة لا تُختلق.
- لا أسماء أو أرقام توضيحية من الصورة في بيانات التطبيق؛ بيانات المعاينة داخل الاختبارات فقط.

## حدود البيانات والوظائف

وُضّحت هذه الاختلافات قبل التنفيذ: لا تتوفر أحجام الملفات في تحميل البيانات الحالي، ولا سحب وإفلات أو حذف مرفقات؛ لم تُضف وظائف لهذه العناصر. نوع المهمة يحل محل سطر القسم/المشروع غير المتاح. الوقت الجاري غير المحفوظ لا يُضاف لإجمالي الساعات؛ تظهر علامة بداية المؤقت الفعلية. القيم غير المتاحة تظهر بشرطة أو حالة فارغة واضحة.

## التحقق

- `flutter test --dart-define=EXPORT_TASK_DETAILS_PREVIEW=true`: نجحت المجموعة الكاملة (59 حالة) أثناء التنفيذ.
- بعد مراجعة الحفاظ على البحث وإضافة اختبار تكبير نص التفاصيل 150%، نجحت 28 حالة في `flutter test test/employee_tasks_test.dart`.
- شمل التحقق العربية والإنجليزية عند 320 و768 و1024 و1440، ورفع/فتح المرفقات عبر callbacks اختبارية، وتحديث المؤقت والعودة إلى القائمة مع الاحتفاظ بالبحث.
- `flutter analyze`: 27 ملاحظة سابقة خارج ملفات التعديل، دون ملاحظات جديدة، ولذلك خرج الأمر برمز 1.
- راجعت بصريًا `build/employee_task_details_preview.png`، ونجح `git diff --check`.
- العمليات الوظيفية اختُبرت بمستودع وهمي وبيانات محلية؛ لم تُنفّذ على بيانات الموظفين الحقيقية.
