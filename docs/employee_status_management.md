# إدارة حالة الموظفين

شغّل `supabase/install_employee_status_management.sql` في Supabase SQL Editor ثم أعد تشغيل التطبيق.
الملف يتضمن فحص حالة الموظف في خدمة تجهيز الحساب؛ لا يلزم إعادة تشغيل ملفات الإضافة القديمة.

- قائمة الموظفين لمدير النظام وHR تبدأ بالموظفين الحاليين، وتشمل فترة التجربة.
- تبويب «غير النشطين / المغادرون» يعرض الموظفين الموقوفين، بما فيهم أصحاب المخالصات النهائية.
- إجراء «إيقاف الموظف» متاح من قائمة الإجراءات ومن ملف الموظف، بعد تأكيد واضح.
- الإيقاف يغيّر حالة الموظف فقط ويوقف حسابات employee/manager المرتبطة داخل الشركة نفسها.
  العقود والرواتب والمستندات والمخالصات تظل مرتبطة بالموظف.
- إعادة التفعيل تعيد الموظف إلى القائمة الحالية. حساب الدخول يُعاد تفعيله بشكل مستقل من إدارة
  المستخدمين بواسطة مدير النظام، حتى لا يتم تجاوز إيقاف حساب سابق لسبب آخر.
- لا يسمح الإجراء بإيقاف سجل موظف مرتبط بحساب إداري أو حساب في شركة مختلفة، ولا بإيقاف سجل
  موظف المستخدم الحالي نفسه. لا يمكن تجهيز حساب لموظف غير نشط أو تفعيل حسابه قبل إعادة تفعيله.
- الموظف الموقوف يظل قابلًا للعرض والبحث في تبويب غير النشطين. لم تتم إضافة حذف نهائي.

التثبيت يوقف كذلك حسابات employee/manager المرتبطة بموظفين غير نشطين بالفعل. لا يحذف حساب Auth؛
يعتمد منع الدخول على حالة حساب التطبيق وسياسات الوصول الحالية. الجلسات القائمة تخضع لسياسات
قاعدة البيانات وفحص الجلسة في التطبيق؛ لا يتم إلغاء رموز Auth بالقوة بواسطة هذا الملف.
