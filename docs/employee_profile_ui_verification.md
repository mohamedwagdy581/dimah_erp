# واجهة الملف الشخصي للموظف

تطبيق المرجع على حساب الموظف العادي فقط، مع الحفاظ على واجهة الحسابات الأخرى والتعديلات السابقة.

## الملفات

- `lib/features/profile/view/profile_page.dart`: اختيار واجهة الموظف حسب دور الجلسة، وربط تغيير كلمة المرور وتسجيل الخروج بالوظائف الحالية.
- `lib/features/profile/view/employee_profile_cubit.dart`: تحميل بيانات الحساب وحفظها عبر `ProfileRepo` الحالي، منع الحفظ المتكرر، ومعالجة الفشل.
- `lib/features/profile/view/employee_profile_view.dart`: بطاقة الاسم والأحرف الأولى، نموذج الاسم والجوال، البريد والدور للقراءة، بطاقتا المعلومات وأمان الحساب، وتخطيط متجاوب عربي وإنجليزي.
- `test/employee_profile_test.dart`: اختبارات التحميل وإعادة المحاولة والحفظ والإلغاء والتحقق من الإدخال واستدعاء الإجراءات والتخطيط بعروض 320 و768 و1440، مع تكبير النص إلى 150% على أصغر عرض.

## حدود الوظائف الحالية

الحفظ يحدّث الاسم والجوال في سجل الحساب من خلال المستودع الحالي. البريد والدور لا يمكن تعديلهما هنا. الصورة الرمزية تستخدم أحرف الاسم الفعلي؛ رفع صورة شخصية ليس متاحًا في الوظائف الحالية. زر تغيير كلمة المرور يفتح الصفحة الموجودة. لم تتغير قاعدة البيانات ولم تُنشر التعديلات إلى GitHub.

## التحقق

- نجحت اختبارات البروفايل البالغ عددها 15، بما فيها تصدير معاينة سطح المكتب ومراجعتها بصريًا.
- نجحت مجموعة الاختبارات كاملة: 115 اختبارًا باستخدام `flutter test --dart-define=EXPORT_PROFILE_PREVIEW=true`.
- `flutter analyze`: 27 تحذيرًا وملاحظة سابقة خارج الملفات الجديدة، دون أخطاء أو ملاحظات في ملفات البروفايل المعدّلة.
- المعاينة المحلية: `build/employee_profile_preview.png`، ببيانات اختبار فقط.
